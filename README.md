## 📦 Getting Started

### Prerequisites
**For Java implementations:**
- Java Development Kit (JDK) 8 or higher
- Any Java IDE (IntelliJ IDEA, Eclipse, VS Code) or command-line compiler

**For Python implementations:**
- Python 3.7 or higher
- Required libraries (install via `pip install -r requirements.txt` if available)

### Running the Sudoku Solver

1. **Clone the repository**
   ```bash
   git clone https://github.com/Aman051103/algoVisualiser.git
   cd algoVisualiser
   ```

2. **Navigate to the Sudoku Solver directory**
   ```bash
   cd sudokuSolverVisualiser
   ```

3. **Compile the Java file**
   ```bash
   javac visualiserCode.java
   ```

4. **Run the application**
   ```bash
   java SudokuSolverGUI
   ```

### Usage
- Enter a Sudoku puzzle in the grid
- Click **"Load Puzzle"** to load a saved puzzle
- Click **"Solve"** to visualize the solving process
- Watch as the algorithm fills in cells step by step!

**Note:** Different algorithm visualizers may be implemented in Java or Python. Check the respective folder's README or code comments for specific instructions.
